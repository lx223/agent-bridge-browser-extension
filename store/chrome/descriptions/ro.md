Controlați propriul browser cu orice agent AI doriți.

Conectați agentul AI de programare la browserul Chrome pe care îl folosiți zilnic, prin Model Context Protocol (MCP).

Agent Browser Bridge permite unui agent conectat să listeze, să deschidă, să aducă în prim-plan și să închidă ferestre și file, să organizeze filele în grupuri cu nume și culori, să mute, să fixeze, să duplice și să descarce din memorie file sau să le dezactiveze sunetul și să închidă file la cerere. Previzualizați un plan de grupare înainte de a-l aplica și anulați ultimul plan pentru a restabili aranjamentul anterior.

Agenții vă pot ajuta și să reluați activitatea anterioară: pot căuta în istoricul de navigare, pot lista filele închise recent și filele deschise pe celelalte dispozitive pe care v-ați conectat, apoi le pot redeschide. Pot căuta și organiza marcajele și Lista de lectură, pot găsi și porni descărcări, pot vedea site-urile pe care le accesați cel mai des, pot căuta cu motorul de căutare prestabilit și vă pot anunța când se încheie o activitate.

Agenții conectați pot, de asemenea, să inspecteze și să opereze pagini web, să navigheze, să dea clic, să tasteze și să folosească instrumentele WebMCP oferite de pagini. Permisiunea de depanare permite acest control al paginilor prin Chrome DevTools Protocol. Conectați doar agenți în care aveți încredere: aceștia pot primi titlurile filelor, adresele URL și conținutul paginilor și pot interacționa cu paginile în numele dvs.

Un panou lateral vă permite să conversați cu agentul din Chrome, astfel încât să nu fie nevoie să reveniți la fereastra agentului între pași.

Pagina de configurare afișează starea conexiunii și oferă opțiuni de configurare pentru Cursor, VS Code, Claude Code și alți agenți compatibili cu MCP. Este necesar un server MCP local Agent Browser Bridge separat. Extensia se conectează la acest server de pe computerul dvs.

Statisticile anonime de utilizare a produsului pot fi dezactivate din setările extensiei. Consultați politica de confidențialitate pentru detalii.
