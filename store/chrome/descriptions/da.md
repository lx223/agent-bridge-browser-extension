Styr din egen browser med den AI-agent, du foretrækker.

Forbind din AI-kodningsagent til din daglige Chrome-browser via Model Context Protocol (MCP).

Med Agent Browser Bridge kan en forbundet agent vise, åbne, fokusere på og lukke vinduer og faner, organisere faner i navngivne og farvede grupper, flytte, fastgøre, duplikere og frigøre faner fra hukommelsen, slå lyden fra i faner samt lukke faner, når du beder om det. Se et eksempel på en grupperingsplan, før du anvender den, og fortryd den seneste plan for at gendanne det tidligere layout.

Agenter kan også hjælpe dig med at genoptage tidligere arbejde: De kan søge i din browserhistorik, vise nyligt lukkede faner og de faner, der er åbne på dine andre enheder, hvor du er logget ind, og genåbne dem. De kan søge i og organisere dine bogmærker og din læseliste, finde og starte downloads, se dine mest besøgte websteder, søge med din standardsøgemaskine og give dig besked, når en opgave er færdig.

Forbundne agenter kan også undersøge og betjene websider, navigere, klikke, skrive og bruge WebMCP-værktøjer, som siderne stiller til rådighed. Debugger-tilladelsen muliggør denne sidestyring via Chrome DevTools Protocol. Forbind kun agenter, du har tillid til: De kan modtage fanetitler, webadresser og sideindhold og interagere med sider på dine vegne.

Et sidepanel giver dig mulighed for at chatte med din agent fra Chrome, så du ikke behøver at skifte tilbage til agentens vindue mellem hvert trin.

Opsætningssiden viser forbindelsesstatus og indeholder konfigurationsmuligheder for Cursor, VS Code, Claude Code og andre MCP-kompatible agenter. Der kræves en separat lokal MCP-server til Agent Browser Bridge. Udvidelsen forbinder til den server på din computer.
