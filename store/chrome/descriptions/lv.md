Vadiet savu pārlūkprogrammu ar jebkuru MI aģentu pēc savas izvēles.

Savienojiet savu MI programmēšanas aģentu ar ikdienā lietoto pārlūkprogrammu Chrome, izmantojot Model Context Protocol (MCP).

Agent Browser Bridge ļauj savienotam aģentam parādīt logu un ciļņu sarakstu, atvērt, aktivizēt un aizvērt logus un cilnes, kārtot cilnes nosauktās un krāsainās grupās, pārvietot, piespraust un dublēt cilnes, izslēgt to skaņu un izlādēt tās no atmiņas, kā arī aizvērt cilnes pēc jūsu pieprasījuma. Pirms grupēšanas plāna lietošanas apskatiet tā priekšskatījumu un atsauciet pēdējo plānu, lai atjaunotu iepriekšējo izkārtojumu.

Aģenti var arī palīdzēt jums turpināt iepriekš iesākto darbu: meklēt jūsu pārlūkošanas vēsturē, parādīt nesen aizvērtās cilnes un cilnes, kas atvērtas citās jūsu ierīcēs, kurās esat pierakstījies, un atvērt tās no jauna. Tie var meklēt un kārtot jūsu grāmatzīmes un Lasīšanas sarakstu, atrast un sākt lejupielādes, parādīt jūsu visvairāk apmeklētās vietnes, meklēt ar jūsu noklusējuma meklētājprogrammu un paziņot jums, kad uzdevums ir pabeigts.

Savienotie aģenti var arī pārbaudīt tīmekļa lapas un darboties tajās: pāriet uz citām lapām, noklikšķināt, rakstīt un izmantot lapas nodrošinātos WebMCP rīkus. Šo lapu vadību, izmantojot Chrome DevTools Protocol, nodrošina atkļūdošanas (debugger) atļauja. Savienojiet tikai tos aģentus, kuriem uzticaties: tie var saņemt ciļņu nosaukumus, URL un lapu saturu, kā arī jūsu vārdā darboties lapās.

Sānu panelī varat tērzēt ar savu aģentu tieši no Chrome, tāpēc starp darbībām nav jāpārslēdzas atpakaļ uz aģenta logu.

Iestatīšanas lapā tiek rādīts savienojuma statuss un piedāvātas konfigurācijas opcijas Cursor, VS Code, Claude Code un citiem ar MCP saderīgiem aģentiem. Nepieciešams atsevišķs lokālais Agent Browser Bridge MCP serveris. Paplašinājums savienojas ar šo serveri jūsu datorā.

Anonīmu produkta lietojuma statistiku var izslēgt paplašinājuma iestatījumos. Plašāka informācija ir pieejama konfidencialitātes politikā.
