Ovládejte svůj vlastní prohlížeč AI agentem, kterého si sami vyberete.

Připojte svého AI agenta pro programování k prohlížeči Chrome, který používáte každý den, přes Model Context Protocol (MCP).

Agent Browser Bridge umožňuje připojenému agentovi vypisovat, otevírat, aktivovat a zavírat okna a karty, uspořádávat karty do pojmenovaných a barevných skupin, přesouvat, připínat, ztlumovat, duplikovat a uvolňovat karty z paměti a na požádání zavírat karty. Plán seskupení si můžete před použitím prohlédnout a poslední plán vrátit zpět, čímž obnovíte předchozí rozložení.

Agenti vám také pomohou navázat na dřívější práci: prohledávat historii prohlížení, vypisovat nedávno zavřené karty a karty otevřené na vašich dalších přihlášených zařízeních a znovu je otevírat. Mohou prohledávat a uspořádávat záložky a seznam četby, vyhledávat a spouštět stahování, zobrazovat nejnavštěvovanější weby, vyhledávat pomocí výchozího vyhledávače a upozornit vás, když se úkol dokončí.

Připojení agenti mohou také prozkoumávat webové stránky a pracovat s nimi: přecházet na adresy, klikat, psát text a používat nástroje WebMCP, které stránka nabízí. Toto ovládání stránek přes Chrome DevTools Protocol umožňuje oprávnění debugger. Připojujte pouze agenty, kterým důvěřujete: mohou získávat názvy karet, adresy URL a obsah stránek a provádět na stránkách akce vaším jménem.

Postranní panel vám umožní chatovat s agentem přímo z Chromu, takže mezi jednotlivými kroky nemusíte přepínat zpět do okna agenta.

Stránka nastavení zobrazuje stav připojení a nabízí možnosti konfigurace pro Cursor, VS Code, Claude Code a další agenty kompatibilní s MCP. Je vyžadován samostatný místní MCP server Agent Browser Bridge. Rozšíření se k tomuto serveru připojuje ve vašem počítači.
