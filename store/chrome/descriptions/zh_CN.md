用您喜欢的任意 AI 智能体控制自己的浏览器。

通过 Model Context Protocol（MCP），将您的 AI 编程智能体连接到您日常使用的 Chrome 浏览器。

借助 Agent Browser Bridge，已连接的智能体可以列出、打开、聚焦和关闭窗口及标签页，将标签页整理到带有名称和颜色的分组中，移动、固定、静音、复制标签页或将其从内存中释放，并按您的要求关闭标签页。您可以在应用分组方案之前先预览，也可以撤销上一个方案，恢复之前的布局。

智能体还能帮您接着处理之前的工作：搜索您的浏览历史记录，列出最近关闭的标签页以及您在其他已登录设备上打开的标签页，并重新打开它们。智能体还可以搜索和整理您的书签和阅读清单，查找和开始下载，查看您最常访问的网站，使用您的默认搜索引擎进行搜索，并在任务完成时通知您。

已连接的智能体还可以检查和操作网页，进行跳转、点击、输入，以及使用网页提供的 WebMCP 工具。“调试程序”权限使扩展程序能够通过 Chrome DevTools Protocol 实现这种网页控制。请只连接您信任的智能体：它们可以获取标签页标题、网址和网页内容，并代表您与网页互动。

您可以通过侧边栏直接在 Chrome 中与智能体聊天，无需在每一步之间切换回智能体的窗口。

设置页面会显示连接状态，并为 Cursor、VS Code、Claude Code 以及其他兼容 MCP 的智能体提供配置选项。此外还需要一个独立的本地 Agent Browser Bridge MCP 服务器。扩展程序会连接到您电脑上的该服务器。

您可以在扩展程序的设置中关闭匿名使用统计信息的分享。详情请参阅隐私权政策。
