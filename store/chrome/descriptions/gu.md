તમારી પસંદના કોઈપણ AI એજન્ટ વડે તમારું પોતાનું બ્રાઉઝર નિયંત્રિત કરો.

Model Context Protocol (MCP) મારફતે તમારા AI કોડિંગ એજન્ટને તમે રોજ વાપરો છો તે Chrome બ્રાઉઝર સાથે કનેક્ટ કરો.

Agent Browser Bridge વડે કનેક્ટ થયેલ એજન્ટ વિન્ડો અને ટૅબની સૂચિ બતાવી શકે છે, તેને ખોલી શકે છે, તેના પર ફોકસ કરી શકે છે અને બંધ કરી શકે છે; ટૅબને નામ અને રંગવાળાં ગ્રૂપમાં ગોઠવી શકે છે; ટૅબ ખસેડી, પિન કરી, મ્યૂટ કરી, ડુપ્લિકેટ કરી અને અનલોડ કરી શકે છે; અને તમે કહો ત્યારે ટૅબ બંધ કરી શકે છે. ગ્રૂપ બનાવવાનો પ્લાન લાગુ કરતાં પહેલાં તેનું પ્રીવ્યૂ જુઓ, અને છેલ્લો પ્લાન પૂર્વવત્ કરીને અગાઉનું લેઆઉટ પાછું લાવો.

એજન્ટ તમને અગાઉનું કામ ફરી હાથ ધરવામાં પણ મદદ કરી શકે છે: તેઓ તમારો બ્રાઉઝિંગ ઇતિહાસ શોધી શકે છે, તાજેતરમાં બંધ કરેલી ટૅબ અને સાઇન ઇન કરેલાં તમારાં અન્ય ડિવાઇસ પર ખુલ્લી ટૅબની સૂચિ બતાવી શકે છે, અને તેને ફરીથી ખોલી શકે છે. તેઓ તમારા બુકમાર્ક અને વાંચન સૂચિમાં શોધ કરી શકે છે અને તેને ગોઠવી શકે છે, ડાઉનલોડ શોધી અને શરૂ કરી શકે છે, તમે સૌથી વધુ મુલાકાત લીધેલી સાઇટ જોઈ શકે છે, તમારા ડિફૉલ્ટ સર્ચ એન્જિન વડે શોધ કરી શકે છે, અને કોઈ કાર્ય પૂરું થાય ત્યારે તમને સૂચના આપી શકે છે.

કનેક્ટ થયેલ એજન્ટ વેબ પેજ તપાસી અને ચલાવી પણ શકે છે, નેવિગેટ કરી શકે છે, ક્લિક કરી શકે છે, ટાઇપ કરી શકે છે અને પેજ દ્વારા આપવામાં આવેલાં WebMCP ટૂલનો ઉપયોગ કરી શકે છે. ડિબગર પરવાનગી Chrome DevTools Protocol મારફતે પેજનું આ નિયંત્રણ શક્ય બનાવે છે. માત્ર એવા જ એજન્ટ કનેક્ટ કરો જેમના પર તમને વિશ્વાસ હોય: તેઓ ટૅબનાં શીર્ષકો, URL અને પેજનું કન્ટેન્ટ મેળવી શકે છે અને તમારા વતી પેજ પર ક્રિયાઓ કરી શકે છે.

સાઇડ પૅનલ વડે તમે Chromeમાંથી જ તમારા એજન્ટ સાથે ચૅટ કરી શકો છો, જેથી દરેક પગલાં વચ્ચે એજન્ટની વિન્ડો પર પાછા જવાની જરૂર ન પડે.

સેટઅપ પેજ કનેક્શનનું સ્ટેટસ બતાવે છે અને Cursor, VS Code, Claude Code તથા MCP સાથે સુસંગત અન્ય એજન્ટ માટે ગોઠવણીના વિકલ્પો આપે છે. એક અલગ સ્થાનિક Agent Browser Bridge MCP સર્વર જરૂરી છે. એક્સ્ટેંશન તમારા કમ્પ્યૂટર પરના તે સર્વર સાથે કનેક્ટ થાય છે.

પ્રોડક્ટના વપરાશના અનામી આંકડા એક્સ્ટેંશનના સેટિંગમાં બંધ કરી શકાય છે. વિગતો માટે ગોપનીયતા નીતિ જુઓ.
