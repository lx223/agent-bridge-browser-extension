用你喜歡的任何 AI 代理程式控制自己的瀏覽器。

透過 Model Context Protocol（MCP），將你的 AI 程式設計代理程式連線至你平常使用的 Chrome 瀏覽器。

Agent Browser Bridge 能讓已連線的代理程式列出、開啟、聚焦和關閉視窗及分頁，將分頁整理成具有名稱和顏色的群組，移動、固定、靜音、複製分頁或將分頁從記憶體中釋放，並依你的要求關閉分頁。你可以在套用分組計畫前先預覽，也可以復原上一個計畫，還原先前的版面配置。

代理程式也能協助你接續先前的工作：搜尋你的瀏覽歷史記錄，列出最近關閉的分頁以及你在其他已登入裝置上開啟的分頁，並重新開啟這些分頁。代理程式還能搜尋及整理你的書籤和閱讀清單、尋找及開始下載、查看你最常造訪的網站、使用你的預設搜尋引擎搜尋，並在工作完成時通知你。

已連線的代理程式還能檢查及操作網頁，例如前往其他網頁、按一下、輸入文字，以及使用網頁提供的 WebMCP 工具。「偵錯工具」權限讓擴充功能能透過 Chrome DevTools Protocol 控制網頁。請只連線你信任的代理程式：它們可以取得分頁標題、網址和網頁內容，並代表你與網頁互動。

你可以透過側邊面板直接在 Chrome 中與代理程式聊天，不必在每個步驟之間切換回代理程式的視窗。

設定頁面會顯示連線狀態，並為 Cursor、VS Code、Claude Code 和其他相容於 MCP 的代理程式提供設定選項。此外還需要一個獨立的本機 Agent Browser Bridge MCP 伺服器。擴充功能會連線至你電腦上的這個伺服器。

你可以在擴充功能的設定中關閉匿名使用統計資料分享功能。詳情請參閱隱私權政策。
