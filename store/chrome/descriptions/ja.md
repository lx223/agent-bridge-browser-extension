お好きな AI エージェントで、自分のブラウザを操作できます。

Model Context Protocol（MCP）を通じて、AI コーディングエージェントを普段お使いの Chrome ブラウザに接続します。

Agent Browser Bridge を使うと、接続したエージェントがウィンドウやタブを一覧表示したり、開いたり、フォーカスしたり、閉じたりできます。さらに、タブを名前と色付きのグループに整理したり、タブの移動、ピン固定、消音、複製、メモリからの解放を行ったり、頼まれたタブを閉じたりすることもできます。グループ分けの計画は適用前にプレビューでき、最後に適用した計画を元に戻して以前のレイアウトを復元することもできます。

エージェントは、以前の作業を再開するお手伝いもします。閲覧履歴を検索したり、最近閉じたタブや、ログインしている他のデバイスで開いているタブを一覧表示して、もう一度開いたりできます。また、ブックマークやリーディング リストの検索と整理、ダウンロードの検索と開始、よくアクセスするサイトの確認、既定の検索エンジンでの検索を行い、タスクが完了したら通知でお知らせすることもできます。

接続したエージェントは、ウェブページの内容を調べて操作することもできます。ページの移動、クリック、入力のほか、ページが提供する WebMCP ツールも使用できます。このページ操作は、「デバッガ」権限により Chrome DevTools Protocol を通じて行われます。信頼できるエージェントだけを接続してください。接続したエージェントはタブのタイトル、URL、ページの内容を受け取り、あなたに代わってページを操作できます。

サイドパネルを使えば Chrome から直接エージェントとチャットできるため、手順ごとにエージェントのウィンドウに切り替える必要はありません。

セットアップ ページには接続状況が表示され、Cursor、VS Code、Claude Code、その他の MCP 対応エージェント向けの設定オプションが用意されています。別途、ローカルの Agent Browser Bridge MCP サーバーが必要です。拡張機能は、お使いのコンピュータ上のこのサーバーに接続します。

匿名の使用統計情報の送信は、拡張機能の設定でオフにできます。詳しくはプライバシーポリシーをご覧ください。
