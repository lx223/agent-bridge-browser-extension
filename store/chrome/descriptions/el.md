Ελέγξτε το δικό σας πρόγραμμα περιήγησης με όποιον πράκτορα AI θέλετε.

Συνδέστε τον πράκτορα AI προγραμματισμού σας με το Chrome που χρησιμοποιείτε καθημερινά μέσω του Model Context Protocol (MCP).

Το Agent Browser Bridge επιτρέπει σε έναν συνδεδεμένο πράκτορα να εμφανίζει λίστα με παράθυρα και καρτέλες, να τα ανοίγει, να τα φέρνει στο προσκήνιο και να τα κλείνει, να οργανώνει καρτέλες σε ομάδες με όνομα και χρώμα, να μετακινεί, να καρφιτσώνει, να κάνει σίγαση, να αντιγράφει και να αποδεσμεύει από τη μνήμη καρτέλες, καθώς και να κλείνει καρτέλες όταν του το ζητάτε. Κάντε προεπισκόπηση ενός σχεδίου ομαδοποίησης πριν το εφαρμόσετε και αναιρέστε το τελευταίο σχέδιο για να επαναφέρετε την προηγούμενη διάταξη.

Οι πράκτορες μπορούν επίσης να σας βοηθήσουν να συνεχίσετε προηγούμενη εργασία: να κάνουν αναζήτηση στο ιστορικό περιήγησης, να εμφανίζουν τις καρτέλες που κλείσατε πρόσφατα και τις καρτέλες που είναι ανοιχτές στις άλλες συσκευές σας όπου έχετε συνδεθεί, και να τις ανοίγουν ξανά. Μπορούν να κάνουν αναζήτηση και οργάνωση στους σελιδοδείκτες και στη Λίστα ανάγνωσης, να βρίσκουν και να ξεκινούν λήψεις, να εμφανίζουν τους ιστότοπους που επισκέπτεστε συχνότερα, να κάνουν αναζήτηση με την προεπιλεγμένη μηχανή αναζήτησης και να σας ειδοποιούν όταν ολοκληρώνεται μια εργασία.

Οι συνδεδεμένοι πράκτορες μπορούν επίσης να εξετάζουν και να χειρίζονται ιστοσελίδες, να πλοηγούνται, να κάνουν κλικ, να πληκτρολογούν και να χρησιμοποιούν εργαλεία WebMCP που παρέχει η σελίδα. Η άδεια εντοπισμού σφαλμάτων (debugger) επιτρέπει αυτόν τον έλεγχο σελίδων μέσω του Chrome DevTools Protocol. Συνδέετε μόνο πράκτορες που εμπιστεύεστε: μπορούν να λαμβάνουν τίτλους καρτελών, διευθύνσεις URL και περιεχόμενο σελίδων και να αλληλεπιδρούν με σελίδες για λογαριασμό σας.

Ένας πλαϊνός πίνακας σάς επιτρέπει να συνομιλείτε με τον πράκτορά σας μέσα από το Chrome, ώστε να μη χρειάζεται να επιστρέφετε στο παράθυρο του πράκτορα ανάμεσα στα βήματα.

Η σελίδα ρύθμισης εμφανίζει την κατάσταση σύνδεσης και παρέχει επιλογές διαμόρφωσης για το Cursor, το VS Code, το Claude Code και άλλους πράκτορες συμβατούς με MCP. Απαιτείται ξεχωριστός τοπικός διακομιστής MCP του Agent Browser Bridge. Η επέκταση συνδέεται σε αυτόν τον διακομιστή στον υπολογιστή σας.

Μπορείτε να απενεργοποιήσετε τα ανώνυμα στατιστικά χρήσης του προϊόντος στις ρυθμίσεις της επέκτασης. Για λεπτομέρειες, ανατρέξτε στην πολιτική απορρήτου.
