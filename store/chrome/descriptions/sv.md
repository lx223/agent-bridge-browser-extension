Styr din egen webbläsare med valfri AI-agent.

Anslut din AI-kodagent till din vanliga Chrome-webbläsare via Model Context Protocol (MCP).

Med Agent Browser Bridge kan en ansluten agent lista, öppna, fokusera och stänga fönster och flikar, ordna flikar i namngivna och färgade grupper, flytta, fästa, duplicera och frigöra flikar från minnet, stänga av ljudet i flikar samt stänga flikar på begäran. Förhandsgranska en grupperingsplan innan du tillämpar den och ångra den senaste planen för att återställa den tidigare layouten.

Agenter kan också hjälpa dig att återuppta tidigare arbete: de kan söka i din webbhistorik, lista nyligen stängda flikar och flikarna som är öppna på dina andra inloggade enheter, och öppna dem igen. De kan söka i och ordna dina bokmärken och din läslista, hitta och starta nedladdningar, se dina mest besökta webbplatser, söka med din standardsökmotor och meddela dig när en uppgift är klar.

Anslutna agenter kan också granska och använda webbsidor, navigera, klicka, skriva samt utnyttja WebMCP-verktyg som sidorna tillhandahåller. Felsökningsbehörigheten möjliggör denna sidstyrning via Chrome DevTools Protocol. Anslut bara agenter du litar på: de kan ta emot fliktitlar, webbadresser och sidinnehåll och interagera med sidor för din räkning.

En sidopanel låter dig chatta med agenten direkt i Chrome, så att du inte behöver växla tillbaka till agentens fönster mellan stegen.

Konfigurationssidan visar anslutningsstatus och erbjuder konfigurationsalternativ för Cursor, VS Code, Claude Code och andra MCP-kompatibla agenter. En separat lokal MCP-server för Agent Browser Bridge krävs. Tillägget ansluter till den servern på din dator.

Anonym användningsstatistik för produkten kan stängas av i tilläggets inställningar. Mer information finns i integritetspolicyn.
