Kontrolin ang sarili mong browser gamit ang anumang AI agent na gusto mo.

Ikonekta ang iyong AI coding agent sa Chrome browser na ginagamit mo araw-araw sa pamamagitan ng Model Context Protocol (MCP).

Sa Agent Browser Bridge, kayang ilista, buksan, i-focus at isara ng nakakonektang agent ang mga window at tab, ayusin ang mga tab sa mga grupong may pangalan at kulay, ilipat, i-pin, i-mute, i-duplicate at i-unload ang mga tab, at isara ang mga tab kapag hiniling. I-preview ang plano ng pagpapangkat bago ito ilapat, at i-undo ang huling plano para ibalik ang dating ayos.

Matutulungan ka rin ng mga agent na ituloy ang naunang trabaho: maghanap sa iyong history ng pag-browse, ilista ang mga kamakailang isinarang tab at ang mga tab na nakabukas sa iba mong device na naka-sign in, at buksan muli ang mga ito. Kaya rin nilang maghanap at mag-ayos ng iyong mga bookmark at Listahan ng babasahin, maghanap at magsimula ng mga download, tingnan ang mga site na pinakamadalas mong bisitahin, maghanap gamit ang iyong default na search engine, at abisuhan ka kapag tapos na ang isang gawain.

Kaya rin ng mga nakakonektang agent na suriin at gamitin ang mga web page, mag-navigate, mag-click, mag-type, at gamitin ang mga WebMCP tool na ibinibigay ng page. Ang pahintulot na debugger ang nagbibigay-daan sa kontrol na ito sa page sa pamamagitan ng Chrome DevTools Protocol. Ikonekta lang ang mga agent na pinagkakatiwalaan mo: matatanggap nila ang mga pamagat ng tab, URL at nilalaman ng page, at makikipag-ugnayan sila sa mga page para sa iyo.

Sa pamamagitan ng side panel, puwede kang makipag-chat sa iyong agent mula sa Chrome, kaya hindi mo na kailangang bumalik sa window ng agent sa pagitan ng mga hakbang.

Ipinapakita ng setup page ang status ng koneksyon at nagbibigay ito ng mga opsyon sa configuration para sa Cursor, VS Code, Claude Code at iba pang agent na compatible sa MCP. Kailangan ng hiwalay na lokal na Agent Browser Bridge MCP server. Kumokonekta ang extension sa server na iyon sa iyong computer.

Puwedeng i-off ang pagbabahagi ng anonymous na istatistika ng paggamit sa settings ng extension. Tingnan ang patakaran sa privacy para sa mga detalye.
