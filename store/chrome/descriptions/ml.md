ഇഷ്ടമുള്ള ഏത് AI ഏജന്റ് ഉപയോഗിച്ചും സ്വന്തം ബ്രൗസർ നിയന്ത്രിക്കുക.

Model Context Protocol (MCP) വഴി നിങ്ങളുടെ AI കോഡിംഗ് ഏജന്റിനെ ദിവസവും ഉപയോഗിക്കുന്ന Chrome ബ്രൗസറുമായി കണക്റ്റ് ചെയ്യുക.

Agent Browser Bridge ഉപയോഗിച്ച്, കണക്റ്റ് ചെയ്ത ഏജന്റിന് വിൻഡോകളും ടാബുകളും ലിസ്റ്റ് ചെയ്യാനും തുറക്കാനും ഫോക്കസ് ചെയ്യാനും അടയ്ക്കാനും; ടാബുകൾ പേരും നിറവുമുള്ള ഗ്രൂപ്പുകളായി ഓർഗനൈസ് ചെയ്യാനും; ടാബുകൾ നീക്കാനും പിൻ ചെയ്യാനും മ്യൂട്ട് ചെയ്യാനും ഡ്യൂപ്ലിക്കേറ്റ് ചെയ്യാനും അൺലോഡ് ചെയ്യാനും; ആവശ്യപ്പെടുമ്പോൾ ടാബുകൾ അടയ്ക്കാനും കഴിയും. ഗ്രൂപ്പിംഗ് പ്ലാൻ പ്രയോഗിക്കുന്നതിന് മുമ്പ് അതിന്റെ പ്രിവ്യൂ കാണുക, അവസാനത്തെ പ്ലാൻ പഴയപടിയാക്കി മുമ്പത്തെ ലേഔട്ട് പുനഃസ്ഥാപിക്കുക.

മുമ്പത്തെ ജോലി തുടരാനും ഏജന്റുകൾക്ക് നിങ്ങളെ സഹായിക്കാനാകും: നിങ്ങളുടെ ബ്രൗസിംഗ് ചരിത്രം തിരയാനും, അടുത്തിടെ അടച്ച ടാബുകളും സൈൻ ഇൻ ചെയ്തിട്ടുള്ള നിങ്ങളുടെ മറ്റ് ഉപകരണങ്ങളിൽ തുറന്നിരിക്കുന്ന ടാബുകളും ലിസ്റ്റ് ചെയ്യാനും, അവ വീണ്ടും തുറക്കാനും അവയ്ക്ക് കഴിയും. നിങ്ങളുടെ ബുക്ക്‌മാർക്കുകളിലും വായനാ ലിസ്റ്റിലും തിരയാനും അവ ഓർഗനൈസ് ചെയ്യാനും, ഡൗൺലോഡുകൾ കണ്ടെത്താനും ആരംഭിക്കാനും, നിങ്ങൾ ഏറ്റവും കൂടുതൽ സന്ദർശിക്കുന്ന സൈറ്റുകൾ കാണാനും, ഡിഫോൾട്ട് സെർച്ച് എഞ്ചിൻ ഉപയോഗിച്ച് തിരയാനും, ഒരു ടാസ്ക് പൂർത്തിയാകുമ്പോൾ നിങ്ങളെ അറിയിക്കാനും അവയ്ക്ക് കഴിയും.

കൂടാതെ, കണക്റ്റ് ചെയ്ത ഏജന്റുകൾക്ക് വെബ് പേജുകൾ പരിശോധിക്കാനും പ്രവർത്തിപ്പിക്കാനും, നാവിഗേറ്റ് ചെയ്യാനും, ക്ലിക്ക് ചെയ്യാനും, ടൈപ്പ് ചെയ്യാനും, പേജ് നൽകുന്ന WebMCP ടൂളുകൾ ഉപയോഗിക്കാനും കഴിയും. ഡീബഗ്ഗർ അനുമതിയാണ് Chrome DevTools Protocol വഴി ഈ പേജ് നിയന്ത്രണം സാധ്യമാക്കുന്നത്. നിങ്ങൾ വിശ്വസിക്കുന്ന ഏജന്റുകളെ മാത്രം കണക്റ്റ് ചെയ്യുക: അവയ്ക്ക് ടാബ് ശീർഷകങ്ങളും URL-കളും പേജ് ഉള്ളടക്കവും ലഭിക്കാനും നിങ്ങൾക്ക് വേണ്ടി പേജുകളിൽ പ്രവർത്തിക്കാനും കഴിയും.

ഒരു സൈഡ് പാനലിലൂടെ Chrome-ൽ നിന്ന് തന്നെ നിങ്ങളുടെ ഏജന്റുമായി ചാറ്റ് ചെയ്യാം, അതിനാൽ ഓരോ ഘട്ടത്തിനിടയിലും ഏജന്റിന്റെ വിൻഡോയിലേക്ക് തിരികെ പോകേണ്ടതില്ല.

സജ്ജീകരണ പേജ് കണക്ഷൻ നില കാണിക്കുകയും Cursor, VS Code, Claude Code, മറ്റ് MCP-അനുയോജ്യ ഏജന്റുകൾ എന്നിവയ്ക്കുള്ള കോൺഫിഗറേഷൻ ഓപ്ഷനുകൾ നൽകുകയും ചെയ്യുന്നു. പ്രത്യേകമായ ഒരു ലോക്കൽ Agent Browser Bridge MCP സെർവർ ആവശ്യമാണ്. വിപുലീകരണം നിങ്ങളുടെ കമ്പ്യൂട്ടറിലെ ആ സെർവറുമായി കണക്റ്റ് ചെയ്യുന്നു.

അജ്ഞാത ഉൽപ്പന്ന ഉപയോഗ സ്ഥിതിവിവരക്കണക്കുകൾ വിപുലീകരണത്തിന്റെ ക്രമീകരണത്തിൽ ഓഫാക്കാം. വിശദാംശങ്ങൾക്ക് സ്വകാര്യതാ നയം കാണുക.
