שליטה בדפדפן שלך בעזרת כל סוכן AI שבוחרים.

אפשר לחבר את סוכן התכנות מבוסס ה-AI שלך לדפדפן Chrome הרגיל שלך דרך Model Context Protocol (MCP).

Agent Browser Bridge מאפשר לסוכן מחובר להציג רשימה של חלונות וכרטיסיות, לפתוח אותם, להעביר אליהם את המיקוד ולסגור אותם, לארגן כרטיסיות בקבוצות עם שמות וצבעים, להעביר, להצמיד, להשתיק, לשכפל ולשחרר מהזיכרון כרטיסיות, ולסגור כרטיסיות לפי בקשה. אפשר לראות תצוגה מקדימה של תוכנית קיבוץ לפני שמחילים אותה, ולבטל את התוכנית האחרונה כדי לשחזר את הסידור הקודם.

סוכנים יכולים גם לעזור לך לחזור לעבודה קודמת: לחפש בהיסטוריית הגלישה, להציג את הכרטיסיות שנסגרו לאחרונה ואת הכרטיסיות שפתוחות במכשירים האחרים שלך שמחוברים לחשבון, ולפתוח אותן מחדש. הם יכולים לחפש ולארגן את הסימניות ואת רשימת הקריאה, למצוא הורדות ולהתחיל הורדות חדשות, לראות את האתרים שבהם ביקרת הכי הרבה, לחפש באמצעות מנוע החיפוש שמוגדר כברירת מחדל ולשלוח לך התראה כשמשימה מסתיימת.

סוכנים מחוברים יכולים גם לבדוק דפי אינטרנט ולתפעל אותם, לנווט, ללחוץ, להקליד ולהשתמש בכלי WebMCP שהדף מספק. הרשאת ניפוי הבאגים מאפשרת את השליטה הזו בדפים דרך Chrome DevTools Protocol. יש לחבר רק סוכנים שסומכים עליהם: הם יכולים לקבל כותרות של כרטיסיות, כתובות URL ותוכן של דפים, ולפעול בדפים בשמך.

חלונית צדדית מאפשרת לך לשוחח עם הסוכן מתוך Chrome, כך שאין צורך לחזור לחלון של הסוכן בין שלב לשלב.

דף ההגדרה מציג את מצב החיבור ומספק אפשרויות הגדרה ל-Cursor, ל-VS Code, ל-Claude Code ולסוכנים אחרים שתואמים ל-MCP. נדרש שרת MCP מקומי נפרד של Agent Browser Bridge. התוסף מתחבר לשרת הזה במחשב שלך.

אפשר להשבית את הנתונים הסטטיסטיים האנונימיים על השימוש במוצר בהגדרות התוסף. פרטים נוספים זמינים במדיניות הפרטיות.
