तुमच्या आवडीच्या कोणत्याही AI एजंटद्वारे तुमचा स्वतःचा ब्राउझर नियंत्रित करा.

Model Context Protocol (MCP) वापरून तुमचा AI कोडिंग एजंट तुम्ही दररोज वापरत असलेल्या Chrome ब्राउझरशी कनेक्ट करा.

Agent Browser Bridge मुळे कनेक्ट केलेला एजंट विंडो आणि टॅबची सूची पाहू शकतो, ते उघडू शकतो, त्यांच्यावर फोकस करू शकतो आणि ते बंद करू शकतो; टॅब नाव आणि रंग दिलेल्या गटांमध्ये व्यवस्थित करू शकतो; टॅब हलवू, पिन करू, म्यूट करू, डुप्लिकेट करू आणि अनलोड करू शकतो; आणि तुम्ही सांगितल्यावर टॅब बंद करू शकतो. गट करण्याचा प्लॅन लागू करण्यापूर्वी त्याचे पूर्वावलोकन पाहा आणि शेवटचा प्लॅन पूर्ववत करून आधीची मांडणी परत आणा.

एजंट तुम्हाला आधीचे काम पुन्हा सुरू करण्यातही मदत करू शकतात: ते तुमचा ब्राउझिंग इतिहास शोधू शकतात, अलीकडे बंद केलेले टॅब आणि साइन इन केलेल्या तुमच्या इतर डिव्हाइसवर उघडे असलेले टॅब यांची सूची दाखवू शकतात, आणि ते पुन्हा उघडू शकतात. ते तुमचे बुकमार्क आणि वाचन सूची शोधू आणि व्यवस्थित करू शकतात, डाउनलोड शोधू आणि सुरू करू शकतात, तुम्ही सर्वाधिक भेट दिलेल्या साइट पाहू शकतात, तुमच्या डीफॉल्ट सर्च इंजिनने शोध घेऊ शकतात, आणि एखादे काम पूर्ण झाल्यावर तुम्हाला सूचित करू शकतात.

कनेक्ट केलेले एजंट वेब पेज तपासू आणि हाताळूही शकतात, नेव्हिगेट करू शकतात, क्लिक करू शकतात, टाइप करू शकतात आणि पेजने दिलेली WebMCP टूल वापरू शकतात. डीबगर परवानगीमुळे Chrome DevTools Protocol द्वारे हे पेज नियंत्रण शक्य होते. फक्त तुमचा विश्वास असलेलेच एजंट कनेक्ट करा: त्यांना टॅबची शीर्षके, URL आणि पेजचा आशय मिळू शकतो आणि ते तुमच्या वतीने पेजवर कृती करू शकतात.

साइड पॅनलमुळे तुम्ही Chrome मधूनच तुमच्या एजंटशी चॅट करू शकता, त्यामुळे प्रत्येक पायरीदरम्यान एजंटच्या विंडोवर परत जाण्याची गरज नाही.

सेटअप पेज कनेक्शनची स्थिती दाखवते आणि Cursor, VS Code, Claude Code आणि इतर MCP-सुसंगत एजंटसाठी कॉन्फिगरेशन पर्याय देते. एक स्वतंत्र स्थानिक Agent Browser Bridge MCP सर्व्हर आवश्यक आहे. एक्स्टेंशन तुमच्या कॉंप्युटरवरील त्या सर्व्हरशी कनेक्ट होते.

उत्पादन वापराची निनावी आकडेवारी एक्स्टेंशनच्या सेटिंग्जमध्ये बंद करता येते. तपशीलांसाठी गोपनीयता धोरण पाहा.
