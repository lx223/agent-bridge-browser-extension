Controla el teu propi navegador amb l'agent d'IA que vulguis.

Connecta el teu agent de programació amb IA al navegador Chrome que fas servir cada dia mitjançant Model Context Protocol (MCP).

Agent Browser Bridge permet que un agent connectat llisti, obri, posi en primer pla i tanqui finestres i pestanyes; organitzi les pestanyes en grups amb nom i color; mogui, fixi, silenciï i dupliqui pestanyes o les alliberi de la memòria, i tanqui pestanyes quan li ho demanis. Previsualitza un pla d'agrupació abans d'aplicar-lo i desfés l'últim pla per restaurar la disposició anterior.

Els agents també et poden ajudar a reprendre la feina que havies deixat: cercar a l'historial de navegació, llistar les pestanyes tancades recentment i les pestanyes obertes als altres dispositius on tens la sessió iniciada, i tornar-les a obrir. Poden cercar i organitzar les teves adreces d'interès i la Llista de lectura, trobar i iniciar baixades, veure els llocs que més visites, fer cerques amb el motor de cerca predeterminat i avisar-te quan s'acabi una tasca.

Els agents connectats també poden examinar pàgines web i actuar-hi: navegar, fer clic, escriure i utilitzar les eines WebMCP que ofereixen les pàgines. El permís de depuració fa possible aquest control de pàgines mitjançant Chrome DevTools Protocol. Connecta només agents de confiança: poden rebre els títols de les pestanyes, els URL i el contingut de les pàgines, i interactuar amb les pàgines en nom teu.

Un tauler lateral et permet xatejar amb el teu agent des de Chrome, de manera que no cal que tornis a la finestra de l'agent entre un pas i un altre.

La pàgina de configuració mostra l'estat de la connexió i ofereix opcions de configuració per a Cursor, VS Code, Claude Code i altres agents compatibles amb MCP. Cal un servidor MCP local d'Agent Browser Bridge independent. L'extensió es connecta a aquest servidor al teu ordinador.

Les estadístiques d'ús anònimes del producte es poden desactivar a la configuració de l'extensió. Consulta la política de privadesa per obtenir-ne més detalls.
