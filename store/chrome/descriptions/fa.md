مرورگرتان را با هر عامل هوش مصنوعی دلخواه کنترل کنید.

عامل برنامه‌نویسی هوش مصنوعی‌تان را از طریق Model Context Protocol (MCP) به مرورگر Chrome روزمره‌تان وصل کنید.

Agent Browser Bridge به عامل متصل امکان می‌دهد پنجره‌ها و برگه‌ها را فهرست کند، باز کند، به جلو بیاورد و ببندد، برگه‌ها را در گروه‌های نام‌دار و رنگی مرتب کند، برگه‌ها را جابه‌جا، سنجاق، بی‌صدا، تکثیر و از حافظه تخلیه کند، و در صورت درخواست شما برگه‌ها را ببندد. پیش از اعمال برنامه گروه‌بندی، پیش‌نمایش آن را ببینید و با لغو آخرین برنامه، چیدمان قبلی را برگردانید.

عامل‌ها همچنین می‌توانند به شما کمک کنند کارهای قبلی را از سر بگیرید: سابقه مرور را جستجو کنند، برگه‌های اخیراً بسته‌شده و برگه‌های باز روی دیگر دستگاه‌هایی را که با حسابتان وارد آن‌ها شده‌اید فهرست کنند و دوباره باز کنند. همچنین می‌توانند نشانک‌ها و فهرست خواندن شما را جستجو و مرتب کنند، بارگیری‌ها را پیدا کنند و بارگیری تازه‌ای شروع کنند، پربازدیدترین سایت‌هایتان را ببینند، با موتور جستجوی پیش‌فرض‌تان جستجو کنند و وقتی کاری تمام شد به شما اطلاع دهند.

عامل‌های متصل همچنین می‌توانند صفحه‌های وب را بررسی کنند و با آن‌ها کار کنند، به صفحه‌های دیگر بروند، کلیک کنند، تایپ کنند و از ابزارهای WebMCP که صفحه ارائه می‌کند استفاده کنند. مجوز اشکال‌زدا این کنترل صفحه را از طریق Chrome DevTools Protocol ممکن می‌کند. فقط عامل‌هایی را وصل کنید که به آن‌ها اعتماد دارید: آن‌ها می‌توانند عنوان برگه‌ها، نشانی‌های وب و محتوای صفحه‌ها را دریافت کنند و از طرف شما با صفحه‌ها تعامل کنند.

یک پانل کناری به شما امکان می‌دهد از داخل Chrome با عامل خود گفتگو کنید، بنابراین لازم نیست بین مراحل به پنجره عامل برگردید.

صفحه راه‌اندازی وضعیت اتصال را نشان می‌دهد و گزینه‌های پیکربندی را برای Cursor، VS Code، Claude Code و دیگر عامل‌های سازگار با MCP ارائه می‌کند. یک سرور MCP محلی جداگانه Agent Browser Bridge لازم است. افزونه به آن سرور روی رایانه شما وصل می‌شود.

آمار استفاده ناشناس از محصول را می‌توانید در تنظیمات افزونه خاموش کنید. برای جزئیات، خط‌مشی حریم خصوصی را ببینید.
