நீங்கள் விரும்பும் எந்த AI ஏஜென்ட் மூலமும் உங்கள் சொந்த உலாவியைக் கட்டுப்படுத்துங்கள்.

Model Context Protocol (MCP) மூலம் உங்கள் AI கோடிங் ஏஜென்ட்டை நீங்கள் தினமும் பயன்படுத்தும் Chrome உலாவியுடன் இணையுங்கள்.

Agent Browser Bridge மூலம், இணைக்கப்பட்ட ஏஜென்ட் சாளரங்களையும் தாவல்களையும் பட்டியலிடலாம், திறக்கலாம், அவற்றுக்கு ஃபோகஸ் செய்யலாம், மூடலாம்; தாவல்களைப் பெயரும் வண்ணமும் கொண்ட குழுக்களாக ஒழுங்கமைக்கலாம்; தாவல்களை நகர்த்தலாம், பின் செய்யலாம், ஒலியடக்கலாம், நகலெடுக்கலாம், அன்லோடு செய்யலாம்; நீங்கள் கேட்கும்போது தாவல்களை மூடலாம். குழுவாக்கும் திட்டத்தைச் செயல்படுத்தும் முன் அதை மாதிரிக்காட்சியாகப் பாருங்கள், கடைசித் திட்டத்தைச் செயல்தவிர்த்து முந்தைய தளவமைப்பை மீட்டெடுங்கள்.

முன்பு செய்த வேலையைத் தொடரவும் ஏஜென்ட்கள் உங்களுக்கு உதவலாம்: அவை உங்கள் உலாவல் வரலாற்றில் தேடலாம், சமீபத்தில் மூடிய தாவல்களையும் நீங்கள் உள்நுழைந்துள்ள பிற சாதனங்களில் திறந்திருக்கும் தாவல்களையும் பட்டியலிடலாம், அவற்றை மீண்டும் திறக்கலாம். உங்கள் புக்மார்க்குகளிலும் வாசிப்புப் பட்டியலிலும் தேடி அவற்றை ஒழுங்கமைக்கலாம், பதிவிறக்கங்களைக் கண்டறிந்து தொடங்கலாம், நீங்கள் அதிகம் பார்வையிட்ட தளங்களைப் பார்க்கலாம், உங்கள் இயல்புத் தேடல் இன்ஜின் மூலம் தேடலாம், ஒரு பணி முடிந்ததும் உங்களுக்கு அறிவிக்கலாம்.

இணைக்கப்பட்ட ஏஜென்ட்கள் இணையப் பக்கங்களை ஆய்வுசெய்யவும் இயக்கவும், வழிசெலுத்தவும், கிளிக் செய்யவும், தட்டச்சு செய்யவும், பக்கம் வழங்கும் WebMCP கருவிகளைப் பயன்படுத்தவும் முடியும். பிழைதிருத்தி அனுமதி, Chrome DevTools Protocol மூலம் இந்தப் பக்கக் கட்டுப்பாட்டைச் சாத்தியமாக்குகிறது. நீங்கள் நம்பும் ஏஜென்ட்களை மட்டுமே இணையுங்கள்: அவை தாவல் தலைப்புகள், URLகள், பக்க உள்ளடக்கம் ஆகியவற்றைப் பெறலாம், உங்கள் சார்பாகப் பக்கங்களில் செயல்படலாம்.

பக்கப் பேனல் மூலம் Chrome-இலிருந்தே உங்கள் ஏஜென்ட்டுடன் அரட்டையடிக்கலாம், எனவே ஒவ்வொரு படிக்கும் இடையில் ஏஜென்ட்டின் சாளரத்திற்குத் திரும்பிச் செல்ல வேண்டியதில்லை.

அமைவுப் பக்கம் இணைப்பு நிலையைக் காட்டுகிறது, மேலும் Cursor, VS Code, Claude Code மற்றும் MCP உடன் இணக்கமான பிற ஏஜென்ட்களுக்கான உள்ளமைவு விருப்பங்களை வழங்குகிறது. தனியாக ஒரு லோக்கல் Agent Browser Bridge MCP சர்வர் தேவை. இந்த நீட்டிப்பு உங்கள் கம்ப்யூட்டரில் உள்ள அந்தச் சர்வருடன் இணையும்.

அநாமதேயத் தயாரிப்புப் பயன்பாட்டுப் புள்ளிவிவரங்களை நீட்டிப்பின் அமைப்புகளில் முடக்கலாம். விவரங்களுக்குத் தனியுரிமைக் கொள்கையைப் பாருங்கள்.
