Управляйте своим браузером с помощью любого ИИ-агента на ваш выбор.

Подключите своего ИИ-агента для программирования к привычному браузеру Chrome через Model Context Protocol (MCP).

Agent Browser Bridge позволяет подключённому агенту просматривать список окон и вкладок, открывать, активировать и закрывать их, упорядочивать вкладки по группам с названиями и цветами, перемещать, закреплять, дублировать и выгружать вкладки, отключать в них звук, а также закрывать вкладки по вашей просьбе. План группировки можно просмотреть перед применением, а последний план можно отменить, чтобы восстановить прежнее расположение вкладок.

Агенты также помогут вернуться к прежней работе: искать в истории браузера, показывать недавно закрытые вкладки и вкладки, открытые на других ваших устройствах, где выполнен вход в аккаунт, и снова открывать их. Они могут искать и упорядочивать закладки и список для чтения, находить и запускать скачивания, показывать самые посещаемые сайты, выполнять поиск с помощью поисковой системы по умолчанию и уведомлять вас о завершении задачи.

Подключённые агенты также могут анализировать веб-страницы и работать с ними: переходить по адресам, нажимать на элементы, вводить текст и использовать инструменты WebMCP, которые предоставляет страница. Разрешение debugger позволяет управлять страницами через Chrome DevTools Protocol. Подключайте только тех агентов, которым доверяете: они могут получать названия вкладок, URL и содержимое страниц и взаимодействовать со страницами от вашего имени.

Боковая панель позволяет общаться с агентом прямо из Chrome, поэтому между шагами не нужно переключаться обратно в окно агента.

На странице настройки отображается статус подключения и доступны параметры конфигурации для Cursor, VS Code, Claude Code и других агентов, совместимых с MCP. Требуется отдельный локальный MCP-сервер Agent Browser Bridge. Расширение подключается к этому серверу на вашем компьютере.

Отправку анонимной статистики использования продукта можно отключить в параметрах расширения. Подробнее см. в политике конфиденциальности.
