원하는 AI 에이전트로 내 브라우저를 제어하세요.

Model Context Protocol(MCP)을 통해 AI 코딩 에이전트를 평소 사용하는 Chrome 브라우저에 연결하세요.

Agent Browser Bridge를 사용하면 연결된 에이전트가 창과 탭을 나열하고, 열고, 포커스를 맞추고, 닫을 수 있습니다. 또한 탭을 이름과 색상이 지정된 그룹으로 정리하고, 탭을 이동, 고정, 음소거, 복제하거나 메모리에서 해제하고, 요청에 따라 탭을 닫을 수 있습니다. 그룹화 계획을 적용하기 전에 미리 보고, 마지막 계획을 실행 취소하여 이전 배치로 되돌릴 수 있습니다.

에이전트는 이전에 하던 작업을 이어서 할 수 있도록 도와주기도 합니다. 방문 기록을 검색하고, 최근에 닫은 탭과 로그인한 다른 기기에서 열려 있는 탭을 나열하고, 다시 열 수 있습니다. 북마크와 읽기 목록을 검색하고 정리하며, 다운로드를 찾고 시작하고, 자주 방문한 사이트를 확인하고, 기본 검색엔진으로 검색하고, 작업이 끝나면 알림을 보낼 수도 있습니다.

연결된 에이전트는 웹페이지를 검사하고 조작할 수도 있습니다. 페이지를 이동하고, 클릭하고, 입력하고, 페이지에서 제공하는 WebMCP 도구를 사용할 수 있습니다. 이러한 페이지 제어는 디버거 권한을 통해 Chrome DevTools Protocol로 이루어집니다. 신뢰할 수 있는 에이전트만 연결하세요. 연결된 에이전트는 탭 제목, URL, 페이지 콘텐츠를 받을 수 있으며 사용자를 대신해 페이지와 상호작용할 수 있습니다.

측면 패널을 사용하면 Chrome에서 바로 에이전트와 채팅할 수 있으므로 단계마다 에이전트 창으로 다시 전환할 필요가 없습니다.

설정 페이지에서는 연결 상태를 확인할 수 있으며 Cursor, VS Code, Claude Code 및 기타 MCP 호환 에이전트를 위한 구성 옵션이 제공됩니다. 별도의 로컬 Agent Browser Bridge MCP 서버가 필요합니다. 확장 프로그램은 내 컴퓨터에서 실행되는 이 서버에 연결됩니다.

익명 사용 통계 공유는 확장 프로그램 설정에서 끌 수 있습니다. 자세한 내용은 개인정보처리방침을 참조하세요.
