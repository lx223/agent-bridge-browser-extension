ನಿಮಗಿಷ್ಟವಾದ ಯಾವುದೇ AI ಏಜೆಂಟ್ ಮೂಲಕ ನಿಮ್ಮ ಸ್ವಂತ ಬ್ರೌಸರ್ ಅನ್ನು ನಿಯಂತ್ರಿಸಿ.

Model Context Protocol (MCP) ಮೂಲಕ ನಿಮ್ಮ AI ಕೋಡಿಂಗ್ ಏಜೆಂಟ್ ಅನ್ನು ನೀವು ಪ್ರತಿದಿನ ಬಳಸುವ Chrome ಬ್ರೌಸರ್‌ಗೆ ಕನೆಕ್ಟ್ ಮಾಡಿ.

Agent Browser Bridge ಮೂಲಕ, ಕನೆಕ್ಟ್ ಆಗಿರುವ ಏಜೆಂಟ್ ವಿಂಡೋಗಳು ಮತ್ತು ಟ್ಯಾಬ್‌ಗಳನ್ನು ಪಟ್ಟಿ ಮಾಡಬಹುದು, ತೆರೆಯಬಹುದು, ಫೋಕಸ್ ಮಾಡಬಹುದು ಮತ್ತು ಮುಚ್ಚಬಹುದು; ಟ್ಯಾಬ್‌ಗಳನ್ನು ಹೆಸರು ಮತ್ತು ಬಣ್ಣವಿರುವ ಗುಂಪುಗಳಾಗಿ ಆಯೋಜಿಸಬಹುದು; ಟ್ಯಾಬ್‌ಗಳನ್ನು ಸರಿಸಬಹುದು, ಪಿನ್ ಮಾಡಬಹುದು, ಮ್ಯೂಟ್ ಮಾಡಬಹುದು, ನಕಲು ಮಾಡಬಹುದು ಮತ್ತು ಅನ್‌ಲೋಡ್ ಮಾಡಬಹುದು; ಹಾಗೂ ನೀವು ಕೇಳಿದಾಗ ಟ್ಯಾಬ್‌ಗಳನ್ನು ಮುಚ್ಚಬಹುದು. ಗುಂಪು ಮಾಡುವ ಪ್ಲಾನ್ ಅನ್ನು ಅನ್ವಯಿಸುವ ಮೊದಲು ಅದನ್ನು ಪೂರ್ವವೀಕ್ಷಿಸಿ, ಮತ್ತು ಕೊನೆಯ ಪ್ಲಾನ್ ಅನ್ನು ರದ್ದುಗೊಳಿಸಿ ಹಿಂದಿನ ಲೇಔಟ್ ಅನ್ನು ಮರುಸ್ಥಾಪಿಸಿ.

ಹಿಂದಿನ ಕೆಲಸವನ್ನು ಮುಂದುವರಿಸಲು ಕೂಡ ಏಜೆಂಟ್‌ಗಳು ನಿಮಗೆ ಸಹಾಯ ಮಾಡಬಹುದು: ಅವು ನಿಮ್ಮ ಬ್ರೌಸಿಂಗ್ ಇತಿಹಾಸದಲ್ಲಿ ಹುಡುಕಬಹುದು, ಇತ್ತೀಚೆಗೆ ಮುಚ್ಚಿದ ಟ್ಯಾಬ್‌ಗಳನ್ನು ಮತ್ತು ಸೈನ್ ಇನ್ ಆಗಿರುವ ನಿಮ್ಮ ಇತರ ಸಾಧನಗಳಲ್ಲಿ ತೆರೆದಿರುವ ಟ್ಯಾಬ್‌ಗಳನ್ನು ಪಟ್ಟಿ ಮಾಡಬಹುದು, ಮತ್ತು ಅವುಗಳನ್ನು ಮತ್ತೆ ತೆರೆಯಬಹುದು. ಅವು ನಿಮ್ಮ ಬುಕ್‌ಮಾರ್ಕ್‌ಗಳು ಮತ್ತು ಓದುವ ಪಟ್ಟಿಯಲ್ಲಿ ಹುಡುಕಬಹುದು ಮತ್ತು ಅವುಗಳನ್ನು ಆಯೋಜಿಸಬಹುದು, ಡೌನ್‌ಲೋಡ್‌ಗಳನ್ನು ಹುಡುಕಬಹುದು ಮತ್ತು ಪ್ರಾರಂಭಿಸಬಹುದು, ನೀವು ಹೆಚ್ಚು ಭೇಟಿ ನೀಡುವ ಸೈಟ್‌ಗಳನ್ನು ನೋಡಬಹುದು, ನಿಮ್ಮ ಡೀಫಾಲ್ಟ್ ಸರ್ಚ್ ಇಂಜಿನ್ ಮೂಲಕ ಹುಡುಕಬಹುದು, ಮತ್ತು ಒಂದು ಕೆಲಸ ಮುಗಿದಾಗ ನಿಮಗೆ ಸೂಚನೆ ನೀಡಬಹುದು.

ಕನೆಕ್ಟ್ ಆಗಿರುವ ಏಜೆಂಟ್‌ಗಳು ವೆಬ್ ಪುಟಗಳನ್ನು ಪರಿಶೀಲಿಸಬಹುದು ಮತ್ತು ನಿರ್ವಹಿಸಬಹುದು, ನ್ಯಾವಿಗೇಟ್ ಮಾಡಬಹುದು, ಕ್ಲಿಕ್ ಮಾಡಬಹುದು, ಟೈಪ್ ಮಾಡಬಹುದು ಮತ್ತು ಪುಟವು ಒದಗಿಸುವ WebMCP ಟೂಲ್‌ಗಳನ್ನು ಸಹ ಬಳಸಬಹುದು. ಡೀಬಗರ್ ಅನುಮತಿಯು Chrome DevTools Protocol ಮೂಲಕ ಈ ಪುಟ ನಿಯಂತ್ರಣವನ್ನು ಸಾಧ್ಯವಾಗಿಸುತ್ತದೆ. ನೀವು ನಂಬುವ ಏಜೆಂಟ್‌ಗಳನ್ನು ಮಾತ್ರ ಕನೆಕ್ಟ್ ಮಾಡಿ: ಅವು ಟ್ಯಾಬ್ ಶೀರ್ಷಿಕೆಗಳು, URL ಗಳು ಮತ್ತು ಪುಟದ ವಿಷಯವನ್ನು ಪಡೆಯಬಹುದು ಮತ್ತು ನಿಮ್ಮ ಪರವಾಗಿ ಪುಟಗಳಲ್ಲಿ ಕ್ರಿಯೆ ನಡೆಸಬಹುದು.

ಸೈಡ್ ಪ್ಯಾನೆಲ್ ಮೂಲಕ ನೀವು Chrome ನಿಂದಲೇ ನಿಮ್ಮ ಏಜೆಂಟ್ ಜೊತೆ ಚಾಟ್ ಮಾಡಬಹುದು, ಹಾಗಾಗಿ ಪ್ರತಿ ಹಂತದ ನಡುವೆ ಏಜೆಂಟ್‌ನ ವಿಂಡೋಗೆ ಹಿಂತಿರುಗಬೇಕಾಗಿಲ್ಲ.

ಸೆಟಪ್ ಪುಟವು ಕನೆಕ್ಷನ್ ಸ್ಥಿತಿಯನ್ನು ತೋರಿಸುತ್ತದೆ ಮತ್ತು Cursor, VS Code, Claude Code ಹಾಗೂ ಇತರ MCP-ಹೊಂದಾಣಿಕೆಯ ಏಜೆಂಟ್‌ಗಳಿಗೆ ಕಾನ್ಫಿಗರೇಶನ್ ಆಯ್ಕೆಗಳನ್ನು ಒದಗಿಸುತ್ತದೆ. ಪ್ರತ್ಯೇಕವಾದ ಸ್ಥಳೀಯ Agent Browser Bridge MCP ಸರ್ವರ್ ಅಗತ್ಯವಿದೆ. ವಿಸ್ತರಣೆಯು ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿರುವ ಆ ಸರ್ವರ್‌ಗೆ ಕನೆಕ್ಟ್ ಆಗುತ್ತದೆ.

ಅನಾಮಧೇಯ ಉತ್ಪನ್ನ ಬಳಕೆಯ ಅಂಕಿಅಂಶಗಳನ್ನು ವಿಸ್ತರಣೆಯ ಸೆಟ್ಟಿಂಗ್‌ಗಳಲ್ಲಿ ಆಫ್ ಮಾಡಬಹುದು. ವಿವರಗಳಿಗಾಗಿ ಗೌಪ್ಯತಾ ನೀತಿಯನ್ನು ನೋಡಿ.
