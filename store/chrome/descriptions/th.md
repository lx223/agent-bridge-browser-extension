ควบคุมเบราว์เซอร์ของคุณเองด้วยเอเจนต์ AI ตัวใดก็ได้ที่คุณชอบ

เชื่อมต่อเอเจนต์ AI สำหรับเขียนโค้ดของคุณเข้ากับเบราว์เซอร์ Chrome ที่คุณใช้ทุกวันผ่าน Model Context Protocol (MCP)

Agent Browser Bridge ช่วยให้เอเจนต์ที่เชื่อมต่ออยู่แสดงรายการ เปิด โฟกัส และปิดหน้าต่างและแท็บ จัดระเบียบแท็บเป็นกลุ่มที่มีชื่อและสี ย้าย ปักหมุด ปิดเสียง ทำสำเนา และนำแท็บออกจากหน่วยความจำ รวมถึงปิดแท็บเมื่อคุณขอได้ คุณดูตัวอย่างแผนการจัดกลุ่มก่อนนำไปใช้ และเลิกทำแผนล่าสุดเพื่อคืนการจัดวางแบบเดิมได้

นอกจากนี้ เอเจนต์ยังช่วยให้คุณกลับไปทำงานที่ค้างไว้ได้ โดยค้นหาประวัติการเข้าชม แสดงรายการแท็บที่ปิดล่าสุดและแท็บที่เปิดอยู่ในอุปกรณ์อื่นๆ ที่คุณลงชื่อเข้าใช้ แล้วเปิดแท็บเหล่านั้นอีกครั้ง เอเจนต์ยังค้นหาและจัดระเบียบบุ๊กมาร์กและรายการเรื่องรออ่าน ค้นหาและเริ่มการดาวน์โหลด ดูเว็บไซต์ที่คุณเข้าชมบ่อยที่สุด ค้นหาด้วยเครื่องมือค้นหาเริ่มต้นของคุณ และแจ้งเตือนคุณเมื่องานเสร็จได้ด้วย

เอเจนต์ที่เชื่อมต่ออยู่ยังตรวจสอบและใช้งานหน้าเว็บ ไปยังหน้าเว็บต่างๆ คลิก พิมพ์ และใช้เครื่องมือ WebMCP ที่หน้าเว็บมีให้ได้ด้วย สิทธิ์ดีบักเกอร์ช่วยให้ควบคุมหน้าเว็บได้ผ่าน Chrome DevTools Protocol เชื่อมต่อเฉพาะเอเจนต์ที่คุณไว้วางใจเท่านั้น เพราะเอเจนต์จะได้รับชื่อแท็บ URL และเนื้อหาของหน้าเว็บ และโต้ตอบกับหน้าเว็บในนามของคุณได้

แผงด้านข้างช่วยให้คุณแชทกับเอเจนต์ได้จาก Chrome คุณจึงไม่ต้องสลับกลับไปที่หน้าต่างของเอเจนต์ระหว่างแต่ละขั้นตอน

หน้าการตั้งค่าจะแสดงสถานะการเชื่อมต่อและมีตัวเลือกการกำหนดค่าสำหรับ Cursor, VS Code, Claude Code และเอเจนต์อื่นๆ ที่รองรับ MCP ทั้งนี้ต้องใช้เซิร์ฟเวอร์ Agent Browser Bridge MCP ภายในเครื่องแยกต่างหาก โดยส่วนขยายจะเชื่อมต่อกับเซิร์ฟเวอร์นั้นในคอมพิวเตอร์ของคุณ

คุณปิดการแชร์สถิติการใช้งานแบบไม่ระบุตัวตนได้ในการตั้งค่าของส่วนขยาย ดูรายละเอียดได้ในนโยบายความเป็นส่วนตัว
