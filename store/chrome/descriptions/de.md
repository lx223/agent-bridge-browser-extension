Steuern Sie Ihren eigenen Browser mit einem KI-Agenten Ihrer Wahl.

Verbinden Sie Ihren KI-Coding-Agenten über das Model Context Protocol (MCP) mit Ihrem alltäglichen Chrome-Browser.

Mit Agent Browser Bridge kann ein verbundener Agent Fenster und Tabs auflisten, öffnen, in den Vordergrund holen und schließen, Tabs in benannte und farbige Gruppen ordnen, Tabs verschieben, anpinnen, stummschalten, duplizieren und entladen sowie Tabs auf Anfrage schließen. Sehen Sie sich einen Gruppierungsplan in der Vorschau an, bevor Sie ihn anwenden, und machen Sie den letzten Plan rückgängig, um die vorherige Anordnung wiederherzustellen.

Agenten können Ihnen auch helfen, frühere Arbeit wieder aufzunehmen, indem sie Ihren Browserverlauf durchsuchen, kürzlich geschlossene Tabs und die geöffneten Tabs auf Ihren anderen angemeldeten Geräten auflisten und diese erneut öffnen. Außerdem können Agenten Ihre Lesezeichen und Ihre Leseliste durchsuchen und organisieren, Downloads finden und starten, Ihre meistbesuchten Websites abrufen, mit Ihrer Standardsuchmaschine suchen und Sie benachrichtigen, wenn eine Aufgabe abgeschlossen ist.

Verbundene Agenten können außerdem Webseiten untersuchen und bedienen, navigieren, klicken, Text eingeben und von Webseiten bereitgestellte WebMCP-Tools verwenden. Die Debugger-Berechtigung ermöglicht diese Steuerung von Webseiten über das Chrome DevTools Protocol. Verbinden Sie nur Agenten, denen Sie vertrauen: Diese können Tab-Titel, URLs und Seiteninhalte empfangen und in Ihrem Namen mit Webseiten interagieren.

Über eine Seitenleiste können Sie direkt in Chrome mit Ihrem Agenten chatten, sodass Sie zwischen den einzelnen Schritten nicht zum Fenster des Agenten zurückwechseln müssen.

Die Einrichtungsseite zeigt den Verbindungsstatus und bietet Konfigurationsoptionen für Cursor, VS Code, Claude Code und andere MCP-kompatible Agenten. Ein separater lokaler MCP-Server von Agent Browser Bridge ist erforderlich. Die Erweiterung verbindet sich mit diesem Server auf Ihrem Computer.

Anonyme Nutzungsstatistiken zum Produkt lassen sich in den Einstellungen der Erweiterung deaktivieren. Weitere Informationen finden Sie in der Datenschutzerklärung.
