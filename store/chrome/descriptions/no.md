Styr din egen nettleser med AI-agenten du foretrekker.

Koble AI-kodeagenten din til Chrome-nettleseren du bruker hver dag, via Model Context Protocol (MCP).

Med Agent Browser Bridge kan en tilkoblet agent liste opp, åpne, fokusere og lukke vinduer og faner, organisere faner i grupper med navn og farge, flytte, feste, dempe og duplisere faner, frigjøre faner fra minnet og lukke faner når du ber om det. Forhåndsvis en grupperingsplan før du tar den i bruk, og angre den siste planen for å gjenopprette den forrige ordningen.

Agenter kan også hjelpe deg med å ta opp igjen tidligere arbeid: De kan søke i nettleserloggen din, vise nylig lukkede faner og fanene som er åpne på de andre påloggede enhetene dine, og åpne dem igjen. De kan søke i og organisere bokmerkene og leselisten din, finne og starte nedlastinger, se de mest besøkte nettstedene dine, søke med standardsøkemotoren din og varsle deg når en oppgave er ferdig.

Tilkoblede agenter kan også inspisere og bruke nettsider, navigere, klikke, skrive og ta i bruk WebMCP-verktøy som sidene tilbyr. Feilsøkingstillatelsen gjør denne sidestyringen mulig via Chrome DevTools Protocol. Koble bare til agenter du stoler på: De kan motta fanetitler, nettadresser og sideinnhold og samhandle med sider på dine vegne.

Et sidepanel lar deg chatte med agenten din fra Chrome, så du slipper å bytte tilbake til agentens vindu mellom hvert steg.

Oppsettsiden viser tilkoblingsstatus og har konfigurasjonsvalg for Cursor, VS Code, Claude Code og andre MCP-kompatible agenter. Det kreves en separat, lokal MCP-server for Agent Browser Bridge. Utvidelsen kobler seg til denne serveren på datamaskinen din.

Anonym bruksstatistikk for produktet kan slås av i innstillingene for utvidelsen. Se personvernerklæringen for mer informasjon.
