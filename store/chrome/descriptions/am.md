የራስዎን አሳሽ በመረጡት ማንኛውም የAI ወኪል ይቆጣጠሩ።

ኮድ የሚጽፍልዎትን የAI ወኪል በModel Context Protocol (MCP) በኩል በየዕለቱ ከሚጠቀሙበት Chrome አሳሽ ጋር ያገናኙ።

Agent Browser Bridge የተገናኘ ወኪል መስኮቶችን እና ትሮችን እንዲዘረዝር፣ እንዲከፍት፣ ወደ ፊት እንዲያመጣ እና እንዲዘጋ፣ ትሮችን ስም እና ቀለም ባላቸው ቡድኖች እንዲያደራጅ፣ ትሮችን እንዲያንቀሳቅስ፣ እንዲሰካ፣ ድምፃቸውን እንዲያጠፋ፣ እንዲያባዛ እና ከማህደረ ትውስታ እንዲያራግፍ፣ እንዲሁም ሲጠይቁት ትሮችን እንዲዘጋ ያስችለዋል። የመቧደን ዕቅድን ከመተግበርዎ በፊት ቅድመ-ዕይታውን ይመልከቱ፣ እና የቀድሞውን አቀማመጥ ለመመለስ የመጨረሻውን ዕቅድ ይቀልብሱ።

ወኪሎች ቀደም ሲል የጀመሩትን ሥራ እንዲቀጥሉም ሊያግዙዎት ይችላሉ፦ የአሰሳ ታሪክዎን መፈለግ፣ በቅርቡ የተዘጉ ትሮችን እና በመለያዎ በገቡባቸው ሌሎች መሣሪያዎችዎ ላይ የተከፈቱ ትሮችን መዘርዘር እና እንደገና መክፈት ይችላሉ። እንዲሁም ዕልባቶችዎን እና የንባብ ዝርዝርዎን መፈለግ እና ማደራጀት፣ ውርዶችን ማግኘት እና አዲስ ውርድ መጀመር፣ በብዛት የሚጎበኟቸውን ጣቢያዎች ማየት፣ በነባሪ የፍለጋ ፕሮግራምዎ መፈለግ፣ እና አንድ ተግባር ሲጠናቀቅ እርስዎን ማሳወቅ ይችላሉ።

የተገናኙ ወኪሎች እንዲሁም ድረ-ገጾችን መመርመር እና መጠቀም፣ ማሰስ፣ ጠቅ ማድረግ፣ መተየብ እና ገጹ የሚያቀርባቸውን የWebMCP መሣሪያዎች መጠቀም ይችላሉ። የማረሚያ ፈቃዱ ይህን የገጽ ቁጥጥር በChrome DevTools Protocol በኩል ያስችላል። የሚያምኗቸውን ወኪሎች ብቻ ያገናኙ፦ የትር ርዕሶችን፣ ዩአርኤሎችን እና የገጽ ይዘቶችን ሊቀበሉ እና እርስዎን ወክለው ከገጾች ጋር መስተጋብር ሊፈጥሩ ይችላሉ።

የጎን ፓነል ከChrome ሳይወጡ ከወኪልዎ ጋር እንዲወያዩ ያስችልዎታል፤ ስለዚህ በደረጃዎች መካከል ወደ ወኪሉ መስኮት መመለስ አያስፈልግዎትም።

የማዋቀሪያ ገጹ የግንኙነት ሁኔታን ያሳያል፤ እንዲሁም ለCursor፣ ለVS Code፣ ለClaude Code እና ከMCP ጋር ተኳሃኝ ለሆኑ ሌሎች ወኪሎች የውቅር አማራጮችን ያቀርባል። የተለየ አካባቢያዊ የAgent Browser Bridge MCP አገልጋይ ያስፈልጋል። ቅጥያው በኮምፒውተርዎ ላይ ካለው ከዚያ አገልጋይ ጋር ይገናኛል።

ስም-አልባ የምርት አጠቃቀም ስታቲስቲክስን በቅጥያው ቅንብሮች ውስጥ ማጥፋት ይችላሉ። ለዝርዝሮች የግላዊነት መመሪያውን ይመልከቱ።
